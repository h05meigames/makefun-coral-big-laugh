One original funny line, 200 characters or fewer, written by `main.ts` to
`/output/entry.txt`. No input, no randomness, no network, no clock — the
same line on every run.

## The line

> I asked my toaster for emotional support at 3 a.m. — it popped up, took one look at my life, and said I'm the one who's burnt out.

130 characters. A toaster that turns the tables on its owner: the appliance
meant to brown bread ends up diagnosing the human instead.

## Run it

```sh
node main.ts
```

Requires Node 22.18+ (uses TypeScript type stripping). Writes the line to
`/output/entry.txt` and prints it to stdout.
